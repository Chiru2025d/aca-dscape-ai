# aca-dscape-ai

## Setup Instructions

### Setting up Git Remote

To configure the git remote URL for this repository, run the following commands:

```bash
cd /Users/chiranjeevir/Downloads/ACA.Dscape.ai-main
git remote set-url origin https://github.com/Chiru2025d/aca-dscape-ai.git
git push -u origin main
```

### Initial Setup

1. Clone the repository:
   ```bash
   git clone https://github.com/Chiru2025d/aca-dscape-ai.git
   ```

2. Navigate to the project directory:
   ```bash
   cd aca-dscape-ai
   ```

3. Verify the remote configuration:
   ```bash
   git remote -v
   ```

The remote should be set to `https://github.com/Chiru2025d/aca-dscape-ai.git`.
